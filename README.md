# Java 콘솔 회원 CRUD

## 프로젝트 소개
Java 문법과 객체지향 구조를 연습하기 위해 구현한 콘솔 기반 회원 관리 프로그램입니다.  
회원가입, 회원 조회, 로그인, 회원 정보 수정, 회원 탈퇴 기능을 제공합니다.

## 기술 스택
- Java
- Collection Framework
- HashMap
- Scanner

## 주요 기능

### 회원가입
- 아이디 중복 검사
- 비밀번호 유효성 검사
- 이메일 형식 검사
- 전화번호 형식 검사 및 하이픈 포맷 변환

### 회원 조회
- 저장된 전체 회원 목록 조회

### 로그인
- 아이디 존재 여부 확인
- 비밀번호 일치 여부 확인

### 회원 정보 수정
- 비밀번호 변경
- 이메일 변경
- 전화번호 변경

### 회원 탈퇴
- 입력한 회원 정보 삭제

## 프로젝트 구조

```text
src/membercrud
├── Main.java            # 프로그램 실행 진입점
├── Ui.java              # 콘솔 입력/출력 처리
├── UserService.java     # 회원 관련 비즈니스 로직
├── Repository.java      # 회원 데이터 저장소
├── User.java            # 회원 도메인 객체
└── SignUpRequest.java   # 회원가입 요청 DTO
```

## 구현 포인트
- `Repository`에서 `HashMap`을 사용해 회원 데이터를 관리했습니다.
- `Ui`, `UserService`, `Repository`로 역할을 나누어 입력 처리, 비즈니스 로직, 데이터 저장 책임을 분리했습니다.
- 회원가입과 수정 과정에서 아이디, 비밀번호, 이메일, 전화번호에 대한 기본 검증을 처리했습니다.

## 한계 및 개선 방향
- 현재 데이터는 메모리에만 저장되어 프로그램 종료 시 사라집니다.
- 추후 파일 저장 또는 DB 연동 방식으로 확장할 수 있습니다.
- 비밀번호는 현재 문자열로 저장되며, 실제 서비스에서는 암호화 처리가 필요합니다.
